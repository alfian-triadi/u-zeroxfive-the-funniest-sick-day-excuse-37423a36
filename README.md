Entry for the [make.fun](https://make.fun/c/u-zeroxfive-the-funniest-sick-day-excuse-37423a36) competition "The Funniest Sick-Day Excuse": one line, under 200 characters, that gets you out of work and gets a laugh.

## The entry

> My ceiling started leaking onto my bed at 4am, so I've spent the morning catching drips in saucepans and I'm taking the day off before the house files for divorce.

**163 characters** (limit: 200).

## How to run

Requires Node 22 or later, no dependencies to install:

```sh
node main.ts
```

It writes the entry line to `/output/entry.txt`, validating first that it is 1–200 characters of real text, then reading the file back to confirm the round-trip is byte-identical.
